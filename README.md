# Flipclock

Prosty zegar HTML z animacją typu flip.

Projekt jest statyczny i działa bez instalowania zależności. Wystarczy otworzyć plik `index.html` w przeglądarce.

## Pliki

- `index.html` - struktura strony
- `styles.css` - wygląd zegara i animacje
- `script.js` - aktualna godzina oraz zmiana kart
