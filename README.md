# Flipclock

A simple HTML clock with a flip animation.

The project is fully static and does not require any dependencies. Open `index.html` in a browser to run it.

## Files

- `index.html` - page structure
- `styles.css` - clock styling and animations
- `script.js` - current time and card updates

# Flipclock

Prosty zegar HTML z animacją typu flip.

Projekt jest statyczny i działa bez instalowania zależności. Wystarczy otworzyć plik `index.html` w przeglądarce.
